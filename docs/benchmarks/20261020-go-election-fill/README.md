The experiment writes every election field directly instead of constructing and copying a 280-byte temporary. Full and summary receipt behavior stays intact, including clearing stale optional checkpoint fields. The compiler reduces the election stack reservation from 1,120 to 856 bytes. This is an implementation result, not a throughput win.
