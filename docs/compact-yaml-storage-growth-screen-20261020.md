The latest private YAML source completes through compact with the same C-exact output and lower work, but remains held. Its matched ordinary-route RSS ratio is **1.186330**, above the **1.10** limit. No runtime, production pin, budget, allowlist or graduation change is promoted, and no throughput comparison follows a failed memory screen.

Each ratio compares its candidate against the qualified prepared-scanner source, not against the previous row. These are separate matched screens; their differences are not an isolated causal estimate of each change. Each retains **six initial plus 120 matched probes**, with alternating roles, shuffled cases and one grammar per process. Every candidate probe passes the absolute 400 B/source-byte ceiling. Seeds are **43301–43320 / 43601–43620 / 43901–43920**.

The first screen exposes an eligibility mistake. The one-MiB reserve probe reports `active=false, whole_lexicon=true` both at byte **66,081** and at **525,101**. Waiting for version ownership leaves the source-density reserve in place. That screen does not establish the performance of the intended observed-density policy.

The corrected policy uses the existing complete-external-lexicon contract at the first staged reserve. It projects the observed mixture of graph and syntax records with 6.25% slack and scales only proposed increases into the existing total capacity ceiling. Published records, IDs, lengths, parser limits and work do not change. A larger retained family is included in the ceiling; an exhausted ceiling refuses growth. On the large YAML witness, Core capacity before publication changes **31,840,112→26,753,260 bytes**. The same 159,821 graph nodes and 121,045 public nodes remain.

The checkpoint prototype keeps the original slice growth for the first 256 records. Later immutable 44-byte records occupy 1,024-slot pages, so appending another page leaves earlier records in place. IDs, SHA-256 receipts, hash-collision byte comparisons and reset behavior remain exact. Accounting includes unused page slots and pointer capacity. Detached recovery clones copy every live page, charge the last page in full, and reject shared backing ranges. Core capacity before publication is **26,479,344 bytes**; the checkpoint record arena charges **2,445,812 bytes**, including its pointer table. Capacity and stable-address evidence are not a qualified allocated-byte, RSS or throughput saving.

All three sources pass full default Core tests, focused root metadata/lifecycle tests, ordinary and explicit-owned YAML **72-step** edit sessions, document-stream/scanner-transition C witnesses including one MiB, memory/pool tests and native API guards. All **50** focused public/whole-request counter comparisons pass, including the old failed compact attempt. Ordinary full node work is **288→232 / 1,156→925**, and whole-request token work is **124→107 / 441→423** on R4 / 8 KiB. Work never rises and reuse never falls. The checkpoint source also passes the full shadow suite, generated collision/ID/digest checks, clone-budget checks and backing-alias regressions.

These are early memory screens, not release qualification. No new all-language invariant fleet, 618-check C fleet, full ledger, strict corpus, race/386 or randomized throughput qualification is claimed for these three sources. Their parent sources' earlier gates do not transfer. The first checkpoint shadow build failed on an old flat-record fixture initializer; the initializer was adapted while retaining its assertions. The failed build and the corrected full shadow results remain archived. The final shadow-only range-proof adjustment is separately pinned; default-runtime tests exclude those tagged files.

A separate single-process liveness probe on the checkpoint source observes **97,096,040 total allocated bytes during the parse** and **59,599,760 reported HeapAlloc bytes** after it, without forced GC. This is attribution on one process, not B/op, a live-object census or comparative evidence. It retains the public tree. Graph and public-tree overlap, remaining growth copies and retained heap remain targets for investigation.
